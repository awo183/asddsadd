# How Machines Learned to See

A two-minute documentary about computer vision, from MIT's 1966 Summer Vision
Project to the neural networks that now watch every frame. It has narration,
real footage and motion graphics.

  (1080p, 30 fps, about 2:01). English subtitles are included as a soft track.
- **Smaller copy:** [`output/how-machines-learned-to-see-720p.mp4`](output/how-machines-learned-to-see-720p.mp4) (720p, 26 MB)

## Second film: The Calmest Man on the Plane

A two-minute true-crime breakdown of the 1971 D.B. Cooper hijacking, made in the
style of psychological-analysis crime channels. It uses FBI archival material
(public domain), a photo of the actual aircraft, NASA b-roll, an animated route
map and a synthesized dark score.

- **Film:** [`output/the-calmest-man-on-the-plane.mp4`](output/the-calmest-man-on-the-plane.mp4) (1080p, 2:03, typewriter-style text), plus a [720p copy](output/the-calmest-man-on-the-plane-720p.mp4)

## Third film: Twenty Boats / Dvacet člunů

A two-minute history explainer in a paper-collage style (cut-out archival photos,
yellow highlighter on 1912 front pages, flat animated maps and charts). It asks why
about 1,500 people died on a ship that carried *more* lifeboats than the law
required. The English and Czech versions share every scene; only the language
changes, and each is timed to its own narration.

## How it's made

Everything is generated by the code in `src/`; nothing was edited by hand.

| Step | File | What it does |
|---|---|---|
| Script | `src/narration.py` | The narration, split into sentences |
| Voice | `src/tts.py` | Neural text-to-speech, run locally (Kokoro). Records when each sentence starts so the picture can cut to it |
| Detection | `src/detect.py` | Runs YOLOX-S (objects) and YuNet (faces) on the real footage and caches every box |
| Examples | `src/crops.py` | Cuts labelled example images out of the footage using those detections |
| Timeline | `src/timeline.py` | Lays the ten scenes out against the length of the voice |
| Picture | `src/scenes_*.py`, `src/fx.py`, `src/render.py` | Draws each scene frame by frame (footage, HUD, charts, animations) and renders the scenes in parallel |
| Sound | `src/audio.py` | Synthesizes an original score and sound effects in numpy, timed to on-screen events, and ducks the music under the voice |
| Final | `src/finalize.py` | Joins the scenes, normalizes loudness to -16 LUFS, and writes the MP4 and SRT |

To rebuild from scratch, run `./make.sh` (Python 3, ffmpeg and network access
to GitHub). It takes about 20–30 minutes on 4 cores.
